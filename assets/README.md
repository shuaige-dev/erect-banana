# Repository assets

This folder holds images referenced by the main README:

- `banner.png` — top banner shown at the top of README (recommended 1280×400)
- `screenshot-before-after.png` — before/after comparison (recommended 1920×1080)
- `cover.png` — used for social previews and B站 cover

Replace these placeholders with your own artwork before going public.

A quick spec for the banner:
- Width: 1280 px (GitHub README looks best at this width)
- Height: 320–400 px
- Format: PNG with transparency, or JPG <200 KB
- Visual: product name + tagline + small banana/PS icon
